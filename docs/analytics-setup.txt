ARSC private analytics - implementation record - 12 October 2026

STATUS: Owner authorised publication and opt-in analytics activation on 12 October
2026. Source configured for activation; live release verification recorded below.

Scope
- Existing GitHub repository and ARSC Cloudflare Worker only.
- Public homepage and three ARSC service pages. No Firefox/client/dashboard tracking.
- Dedicated D1 database arsc-analytics, ID 61037534-e5fd-4502-bdef-c073cfc7125c.
- Binding ARSC_ANALYTICS; migration migrations/analytics/0001_daily_counts.sql.
- Existing KV bindings, scheduled client refresh and enquiry delivery unchanged.

Privacy and measurements
- Explicit opt-in before events; decline, withdrawal, DNT and GPC respected.
- Device stores only allow/deny preference and expiry (180 days), no visitor ID.
- Four events: page_view, enquiry_start, enquiry_accepted and email_click.
- Once per action per page load, batched; not unique users or linked conversions.
- Accepted is browser-reported server acceptance, NOT verified inbox delivery.
- Analytics storage contains UTC day, one of four allowed paths, event and count.
- No IP addresses, user agents, URLs with queries, names, emails or form values.
- Cloudflare still processes HTTP requests and owner identity; not anonymous hosting.
- Reports cover the last 365 UTC days. New rows trigger cleanup of older daily totals.
- No activity means cleanup waits for the next insert. Provider backups may retain
  deleted totals temporarily (D1 Free Time Travel currently seven days).
- No scrolling/frame tracking, session recordings, heatmaps or continuous polling.
- Browser analytics JS/CSS compressed approximately 2.7 kB combined before latest copy edit.

Access and configuration
- Cloudflare Access app ARSC Private Analytics protects /analytics and descendants.
- App ID f210307f-0b8e-43b4-8b6a-db6be5c3c7ab.
- One owner-only email rule, no public allow or bypass. Team rapid-rice-7f9a.
- Owner identity stored as ANALYTICS_OWNER_EMAIL encrypted Worker secret, NOT source.
- Source contains only public team/AUD identifiers; RS256 JWT validates signature,
  issuer, audience, expiry and exact owner email before dashboard/report/export.
- HTTP-only and path-scoped Access cookies configured; 24-hour session.
- ANALYTICS_ENABLED is true for the owner-authorised release.
- All config bindings and private access configuration must exist to enable tracking.
- Do not deploy the preparatory secret-only Worker version: publish current source
  retaining the prepared secret. Never print secret values into logs or source.
