Metric definitions

Engagements

Likes + comments + shares + reposts + saves, using only values genuinely supplied by the platform.

Engagement rate

Engagements ÷ reach × 100. N/A when reach is zero or unavailable.

Share rate

Shares and non-duplicated reposts ÷ reach × 100.

Save / comment rate

The relevant action ÷ reach × 100.

Follower growth

Ending followers − starting followers. Per-post follows remain N/A unless the provider supplies attribution.

ManyChat Automation CTR

Provider-defined CTR, or link clicks ÷ automation sends × 100 when only those inputs are available.

Video completion rate

Completions ÷ compatible video starts × 100. Video views are never substituted for completions.

Mention change

Current mentions compared with the previous equal-length period. If the prior value is zero, only absolute change is shown.

Missing data

N/A means the source does not supply the metric or the source is unavailable. It never means zero.
