THE GIVING TABLE / EVENT CREATIVE

A guest speaker.
A clear invitation.

An event graphic has several jobs: introduce the speaker, make the practical details easy to find and give the audience a next step. This ARSC artwork brings those elements into one promotional visual for The Giving Table.

THE DESIGN / WHAT YOU CAN SEE

One visual. Three clear priorities.

01

Introduce the speaker

Erika Cramer’s name and portrait dominate the composition. The Giving Table’s logo sits above the invitation, connecting the featured speaker with the event brand.

02

Group the details

The date, venue and time sit together in a bordered block. That grouping separates practical information from the speaker’s introduction.

03

Make the next step visible

A ticket announcement leads into a contrasting red “Book Now” panel. The artwork communicates an intended action; this image is not a working booking form.

THE DELIVERABLE

The proof is the work itself.

The finished graphic shows ARSC’s event-promotion creative: a speaker-led layout, grouped event information and a prominent call to action. This deliverable-focused case study explores those observable design choices.
